Back up sessions and presets

This page copies the sessions and presets stored on an SMK-37 Pro running Tonitor to a file on this computer, and puts them back from that file. Use it before you try another firmware (it may erase or overwrite them): when you reinstall Tonitor, restore the file here. It works in a desktop Chrome, Edge or Opera, over USB MIDI, and needs Tonitor on the keyboard. Nothing is uploaded anywhere: the file stays on this computer.

Not connected

Connect the SMK-37 with a USB data cable, switch it on, then find it.

On the SMK-37
In the file
no file opened

Restore

Open a backup file, then write it to the SMK-37. Every session and preset table in the file replaces the one with the same number on the keyboard; the others on the keyboard are kept.

Notes

  • Close any other program using MIDI (a DAW, M-VAVE's app), and allow MIDI access when the browser asks: the sessions travel as MIDI system-exclusive messages.
  • The keyboard keeps playing while this page works, but writing to its flash silences the audio for a moment each time.
  • Each session and preset table is copied whole and checked: one that does not arrive intact is not written.

The page (js/backup.js) and the part of the firmware that answers it (firmware/src/backup.c) are GPL-3.0, on GitHub.
